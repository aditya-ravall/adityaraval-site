# Aditya Raval — Personal Cybersecurity Portfolio

Personal portfolio website for Aditya Raval, a BCA Cyber Security student and freelance frontend developer. Showcases projects, certifications, and professional profile.

## Structure

```
adityaraval-site/
├── index.html                  # Main HTML entry point
├── css/
│   ├── style.css                # Reset, root variables, base typography, and layout utilities
│   ├── components.css           # Nav, hero, stats, about, capabilities, projects, certifications, contact, send-message, footer, lightbox, reveal system
│   └── responsive.css           # Media query breakpoints and responsive overrides
├── js/
│   ├── main.js                  # Entry point / magnetic button interactions
│   ├── navigation.js             # Active nav-link tracking and hamburger menu
│   ├── animations.js             # Scroll reveal system and count-up statistics
│   ├── particles.js              # Hero particle canvas background
│   └── certifications.js         # Certificate lightbox
├── assets/
│   ├── images/
│   │   ├── aditya-photo.jpg
│   │   └── favicon.png
│   ├── certifications/
│   │   ├── acmegrade.jpg
│   │   ├── Deloitte.png
│   │   └── Commonwealth.png
│   └── resume/
│       └── Aditya_Raval_Resume.pdf
├── README.md
└── .gitignore
```

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Responsive portfolio layout
- Interactive particle background
- Scroll reveal animations
- Project showcase
- Certifications with lightbox
- Responsive navigation
- Social links
- Resume access
- Contact section

## Usage

This is a static website with no build step or dependencies. Open `index.html` directly in a browser, or serve the folder with any static file server (e.g. VS Code Live Server, Vercel).
